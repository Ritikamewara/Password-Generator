# 🔐 Password Generator & Manager

A Streamlit-based web app to generate and manage passwords.

## 🚀 Features
- Generate strong passwords
- Password strength checker
- Copy to clipboard
- Save & view passwords
- Download saved data

## 🛠️ Tech Stack
- Python
- Streamlit
- Pyperclip

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
